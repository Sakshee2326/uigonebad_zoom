# uigonebad_zoom
A chaotic Zoom-style meeting UI that combines realistic video-conferencing features with intentionally broken interactions, ragebait, glitches, and unpredictable UI behavior.  A fun experiment in turning good UX into terrible UX.
🖥️ UI GONE BAD — Zoom Rage

UI GONE BAD — Zoom Rage is a deliberately chaotic Zoom-style meeting experience that combines familiar video-conferencing functionality with frustrating, unpredictable, and entertaining UI behavior.

✨ What is UI GONE BAD?

The project explores what happens when normal UI/UX rules are intentionally broken. Instead of making the interface completely unusable, it keeps the core meeting experience functional while adding unexpected interactions that make users question every click.

🎭 The Experience

The interface follows a simple idea:

70% Realistic Zoom + 30% UI GONE BAD

The meeting should feel familiar enough to use, but unpredictable enough that you never know what will happen after the next click.

Buttons move.
Controls refuse to cooperate.
Messages appear at the worst possible time.
The UI suddenly zooms away.
And sometimes, the interface simply decides that you've had enough.

▶️ Running the Project

Clone the repository and open the project in a modern browser.

For camera, microphone, and screen-sharing functionality, use a local development server so the browser's media APIs work correctly.

🎯 Goal

UI GONE BAD is an experimental UI/UX project focused on ragebait design, interaction design, motion, and controlled chaos.

It asks one question:

What if bad UI wasn't a mistake, but the entire point?
